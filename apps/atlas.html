Where languages meet

How it works

Reading the code

Nothing about your project is uploaded or kept. When you map it, the appliance reads it where it lives: a repository at the commit its branch or tag points to now (fetched once without history, then kept by commit — a commit never changes), or a folder in the workspace the appliance owner mounted, read afresh each time. TypeScript, JavaScript, Python, Go, Rust, C, C++, C#, Ruby, PHP, Kotlin, Scala and Swift are parsed with tree-sitter, tolerant of code that does not compile; Java's names are resolved through the file's own imports and types. Each file is bounded in size and parse time, and one that is skipped is reported.

One model for every language

Every language's files, declarations, imports and calls are children of the same parents — Source, SourceDeclaration, SourceImport, CallSite — so each view below is one query over all of them. Endpoints come from route styles kept as data (how each framework declares a route), not code: a framework the atlas does not know is a row to add.

Honest about calls

Syntax names a call's target but cannot say which function it is. Outside Java a call is matched by name, and every call row says so (resolution: name). "Who calls save" lists every call to something called save.

Asking

Ask finds the code two ways at once and merges them by declaration. By name: the question's words, stemmed and split, against every declaration's name, read live (MatchDeclarations), so it answers the moment a project is added. By meaning: the code index, which keeps each type, function and method as a document and embeds it on a 15-minute schedule (SearchCode); the panel says how many of the project's declarations it holds and whether it is reading now (IndexState and the realm's status). The best are read as the project holds them now (Declarations), and the first eight go to the model numbered, each with its code and what calls it and what it calls (AnswerFromCode, one synthesize call), and it explains how the code works, citing each declaration it relied on. Calls are matched by name. Each view reads only what it is asked about — the files the found declarations are in, the code that mentions their names, the declarations their code names — never the whole project, so a large project answers as fast as a small one. Asking about a project not yet indexed records it (an IndexedProject) and, where the appliance offers it, starts the code index at once.

Every view, with the Cypher that runs

ProjectLanguages — What a project is written in: files, lines and syntax errors per language. The first question to ask of an unfamiliar repository.
MATCH (p:CodeProject {key: $project})-[:HAS_SOURCE]->(s:Source)
RETURN s.language AS language, count(s) AS files, sum(s.lines) AS lines, sum(coalesce(s.errors, 0)) AS syntaxErrors
Routes — Every HTTP endpoint a project declares, whatever its language and framework: Spring and Kotlin mappings, ASP.NET attributes, NestJS and FastAPI decorators, Rocket attributes, Express, Gin and Laravel router calls, Django URL patterns, Rails resources — with the method, the path, the handler and the line (`test` marks one declared in a test file). Also the paths routes sit under (role prefix), whole REST resources (role resource) and calls the code makes to other services (role client). Matched by the route styles in reference data (RouteStyle); a framework missing there is a row to add, not code to write. Paths are as each route writes them: a route's full path is the prefix row in the same file (a class's @RequestMapping, [Route] or @Controller) joined to its own. A Rails or DRF resource is one row for the REST resource it declares.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration)
WHERE size(d.annotationText) > 0
MATCH (s:RouteStyle {shape: 'annotation'})
WHERE d.language IN s.languages
WITH d, s, [t IN d.annotationText WHERE toLower(t) CONTAINS s.pattern] AS hits
WHERE size(hits) > 0
WITH d, s, hits[0] AS a
RETURN s.role AS role, s.method AS method,
       CASE WHEN a CONTAINS '"' THEN split(a, '"')[1] WHEN a CONTAINS "'" THEN split(a, "'")[1] ELSE '' END AS path,
       s.framework AS framework, d.language AS language,
       CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS handler,
       a AS declaredAs, toLower(d.path) CONTAINS 'test' AS test, d.path AS file, d.fromLine AS line, d.url AS url
UNION ALL
MATCH (p:CodeProject {key: $project})-[:CALLS]->(c:CallSite)
WHERE size(c.arguments) > 0
MATCH (s:RouteStyle {shape: 'call'})
WHERE c.method = s.pattern AND c.language IN s.languages AND (size(s.receivers) = 0 OR c.receiver IN s.receivers)
WITH c, s, c.arguments[0] AS first
WHERE first STARTS WITH '"' OR first STARTS WITH "'" OR first STARTS WITH '`' OR first STARTS WITH "r'" OR first STARTS WITH 'r"' OR first STARTS WITH ':'
WITH c, s, first, [a IN tail(c.arguments) WHERE NOT a =~ '[A-Za-z_][A-Za-z0-9_]*\\s*(:|=)[^:=>].*'] AS named
WITH c, s, first, CASE WHEN size(named) = 0 THEN c.enclosing ELSE named[size(named) - 1] END AS h
RETURN s.role AS role, s.method AS method,
       replace(replace(replace(CASE WHEN first STARTS WITH 'r' OR first STARTS WITH ':' THEN substring(first, 1) ELSE first END, '"', ''), "'", ''), '`', '') AS path,
       s.framework AS framework, c.language AS language,
       CASE WHEN size(h) > 60 THEN '(inline) ' + substring(h, 0, 48) + '…' ELSE h END AS handler,
       c.receiver + '.' + c.method + '(…)' AS declaredAs, toLower(c.path) CONTAINS 'test' AS test, c.path AS file, c.line AS line, c.url AS url
UNION ALL
MATCH (p:CodeProject {key: $project})-[:DECLARES_TYPE]->(t:JavaCodeType)
WHERE size(t.annotationText) > 0
MATCH (s:RouteStyle {shape: 'annotation', role: 'prefix'})
WHERE 'java' IN s.languages
WITH t, s, [x IN t.annotationText WHERE toLower(x) CONTAINS s.pattern] AS hits
WHERE size(hits) > 0
WITH t, s, hits[0] AS a
RETURN s.role AS role, s.method AS method,
       CASE WHEN a CONTAINS '"' THEN split(a, '"')[1] ELSE '' END AS path,
       s.framework AS framework, 'java' AS language, t.name AS handler,
       a AS declaredAs, toLower(t.path) CONTAINS 'test' AS test, t.path AS file, t.line AS line, t.url AS url
ORDER BY role, test, path, method
SharedNames — Names declared in more than one language of the same project — the vocabulary a backend and its frontend share (an Item model in Python and an Item interface in TypeScript), or code ported from one language to another. Types, functions and methods only.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration)
WHERE d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'type', 'protocol', 'function', 'method', 'object']
  AND size(d.name) > 3
WITH d.name AS name, collect(DISTINCT d.language) AS languages, collect(DISTINCT d.language + ' ' + d.kind + ' in ' + d.path) AS where
WHERE size(languages) > 1
RETURN name, languages, size(languages) AS languageCount, where
ORDER BY languageCount DESC, name LIMIT 200
ExternalDependencies — What a project imports from outside itself, per language: every module, package or header its files import that is not a relative path, with how many files import it. The dependencies that matter are the ones the code actually uses.
MATCH (p:CodeProject {key: $project})-[:IMPORTS]->(i:SourceImport)
WHERE i.imported <> '' AND NOT i.imported STARTS WITH '.' AND NOT i.imported STARTS WITH '/'
RETURN i.language AS language, i.imported AS imported, count(DISTINCT i.path) AS files
ORDER BY files DESC, imported LIMIT 300
DocCoverage — How much of a project is documented, per language and kind: declarations of types, functions and methods, and how many carry a doc comment or docstring.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration)
WHERE d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'function', 'method', 'constructor']
WITH d.language AS language, d.kind AS kind, count(d) AS declared, sum(CASE WHEN coalesce(d.javadoc, '') <> '' THEN 1 ELSE 0 END) AS documented
RETURN language, kind, declared, documented, round(100.0 * documented / declared) AS percent
ORDER BY language, declared DESC
LargestFunctions — The longest functions and methods in a project, in every language — where complexity lives, and the first candidates to split.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration)
WHERE d.kind IN ['function', 'method', 'constructor']
RETURN d.language AS language, CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS name,
       d.toLine - d.fromLine + 1 AS lines, d.signature AS signature, d.path AS file, d.fromLine AS line, d.url AS url
ORDER BY lines DESC LIMIT 25
WhereDefined — Where a name is declared, in every language: a class, function, method, field or constant called exactly this, with its kind, owner, signature, doc and line. Java's types are matched by their simple name.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration {name: $name})
RETURN d.language AS language, d.kind AS kind, d.owner AS owner, d.name AS name, d.signature AS signature,
       d.javadoc AS doc, d.path AS file, d.fromLine AS line, d.url AS url
UNION ALL
MATCH (p:CodeProject {key: $project})-[:DECLARES_TYPE]->(t:JavaCodeType {simpleName: $name})
RETURN 'java' AS language, t.kind AS kind, '' AS owner, t.name AS name, t.kind + ' ' + t.simpleName AS signature,
       '' AS doc, t.path AS file, t.line AS line, t.url AS url
WhoCalls — Every call to a name, in every language a project is written in tree-sitter reads, with what it is called on, its arguments and the function it is in. Calls are matched by NAME (resolution 'name'): this is every call to something called that, not proof of which one — the receiver says more. Java calls are not listed here; its jar and source realms resolve them exactly.
MATCH (p:CodeProject {key: $project})-[:CALLS]->(c:CallSite {method: $name})
RETURN c.language AS language, c.receiver AS receiver, c.method AS method, c.arguments AS arguments,
       c.enclosing AS caller, c.resolution AS resolution, c.path AS file, c.line AS line, c.url AS url
ORDER BY file, line LIMIT 1000
SearchCode — Code found by what it does: the declarations of an indexed project whose purpose is closest to a description, in every language tree-sitter reads, best first. Ask in words ("retry with backoff", "where money is formatted"), not names; WhereDefined finds names. A project is searchable once it is an IndexedProject and the code-declarations source has run. Each row is what the index holds — the declaration's language, kind, name and file — and `id`, the declaration's key, the same one its document is named by (code://<id>), which a new commit or a move leaves as it is. Declarations(ids) reads the live rows: signature, doc, line, url and code, and none for a declaration the project no longer has (the index drops it on its next run).
MATCH (c:Concept {value: $query})-[r:RELEVANT_TO]->(doc:CodeSearchHit)
WHERE 'code' IN doc.tags AND doc.uri STARTS WITH 'code://' + CASE WHEN $project STARTS WITH 'https://' THEN substring($project, 8) ELSE $project END + '!'
WITH doc, r ORDER BY r.score DESC LIMIT 20
WITH substring(doc.uri, 7) AS key, doc.title AS title, r.score AS score,
     size(CASE WHEN $project STARTS WITH 'https://' THEN substring($project, 8) ELSE $project END) + 1 AS at
WITH key, title, score, split(substring(key, at), '#') AS parts
WITH key, title, score, parts[0] AS file, split(parts[1], ':')[0] AS kind, split(substring(parts[1], size(split(parts[1], ':')[0]) + 1), '~')[0] AS name
RETURN split(split(substring(title, size(name) + 2), ' ')[0], ')')[0] AS language, kind, name, file, score, key AS id
ORDER BY score DESC
IndexedProjects — The projects kept searchable by meaning: each one's declarations are read by the code-declarations documents source every 15 minutes, and only declarations whose text changed are embedded again.
MATCH (ip:IndexedProject)
RETURN ip.key AS project, ip.label AS label
ORDER BY project
IndexState — How much of a project the code index holds: whether it is an IndexedProject, how many of its declarations are held as searchable documents (`indexed`), and when the last was indexed (epoch ms). Search by meaning sees only what is indexed; MatchDeclarations reads every declaration live. The code-declarations source's progress, when a run is under way, is in the realm's status.
OPTIONAL MATCH (ip:IndexedProject {key: $project})
WITH ip IS NOT NULL AS registered
OPTIONAL MATCH (doc:Document)
WHERE doc.uri STARTS WITH 'code://' + CASE WHEN $project STARTS WITH 'https://' THEN substring($project, 8) ELSE $project END + '!'
RETURN registered, count(doc) AS indexed, max(doc.ingestionEpochMs) AS lastIndexedAt
MatchDeclarations — The declarations of an indexed project whose names hold a question's words, read live from the source tree — no embeddings, so it answers the moment a project is indexed, before any document exists. `terms` is the question's words, lower case, space separated, already stemmed ('security configuration', 'jwt validat'). A declaration is found by a term in its name; it then ranks by the terms its name holds (most), its owner's and its path's, and — where the name holds none of them that start a word — its code's (least); a name the words cover more of ranks higher. In a name a term must start a word (camelCase, snake_case or an acronym) to count most, so 'valid' ranks validateToken and JWTValidator above InvalidPasswordException. SecurityConfiguration matches 'security configuration'; test code ranks below the code it tests. Best first, with the same `id` SearchCode returns. Code that holds the words but is not named for them is SearchCode's to find.
MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(d:CodeDeclaration)
WHERE d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'object', 'type', 'function', 'method', 'constructor']
  AND any(t IN split(toLower($terms), ' ') WHERE size(t) > 1 AND toLower(d.name) CONTAINS t)
WITH d ORDER BY d.fromLine, d.id
WITH d.path AS path, d.kind AS kind, coalesce(d.owner, '') AS owner, d.name AS name, collect(d) AS same
UNWIND range(0, size(same) - 1) AS i
WITH same[i] AS d, CASE WHEN $project STARTS WITH 'https://' THEN substring($project, 8) ELSE $project END + '!' + path + '#' + kind + ':'
         + CASE WHEN owner = '' THEN name ELSE owner + '.' + name END + CASE WHEN i = 0 THEN '' ELSE '~' + toString(i + 1) END AS key,
     [t IN split(toLower($terms), ' ') WHERE size(t) > 1] AS ts
WITH d, key, ts, size([t IN ts WHERE toLower(d.name) STARTS WITH t OR d.name CONTAINS toUpper(substring(t, 0, 1)) + substring(t, 1)
                            OR d.name CONTAINS toUpper(t) OR toLower(d.name) CONTAINS '_' + t]) AS inName,
     size([t IN ts WHERE toLower(coalesce(d.owner, '')) CONTAINS t]) AS inOwner,
     size([t IN ts WHERE toLower(d.path) CONTAINS t]) AS inPath,
     size([t IN ts WHERE toLower(coalesce(d.text, '')) CONTAINS t]) AS inText
WHERE size(ts) > 0 AND inName + inOwner + inText > 0
WITH d, key, inName, inOwner, inPath, inText,
     (3.0 * inName + CASE WHEN inName = size(ts) THEN 0.0 ELSE 1.0 * inOwner END + 0.5 * inPath + CASE WHEN inName = 0 THEN 0.75 * inText ELSE 0.0 END) / size(ts)
     + CASE WHEN inName = size(ts) THEN 1.0 ELSE 0.0 END
     + 0.5 * reduce(n = 0, t IN ts | n + CASE WHEN toLower(d.name) CONTAINS t THEN size(t) ELSE 0 END) / size(d.name)
     + CASE WHEN d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'object', 'type'] THEN 0.5
            WHEN d.kind = 'constructor' THEN -0.5 ELSE 0.0 END
     - CASE WHEN toLower(d.path) CONTAINS 'test' THEN 1.5 ELSE 0.0 END AS score
RETURN d.language AS language, d.kind AS kind, CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS name,
       d.signature AS signature, d.javadoc AS doc, d.path AS file, d.fromLine AS line, d.url AS url, score,
       inName AS termsInName, inText AS termsInCode, key AS id
ORDER BY score DESC, line LIMIT 25
Declarations — Declarations of an indexed project by key ('|' between them), in the order given, as the project reads now: language, kind, name, signature, doc, file, line and url, and `code` — a function's lines, numbered, or a type's members, up to about 6,000 characters (what AnswerFromCode reads of the first three). Reads only the files the keys name, so it answers in about a second however large the project. No row for a key the project no longer declares. What SearchCode's hits and an answer's citations lead to.
MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(d:CodeDeclaration)
WHERE any(i IN split($ids, '|') WHERE i CONTAINS ('!' + d.path + '#'))
WITH d ORDER BY d.fromLine, d.id
WITH d.path AS path, d.kind AS kind, coalesce(d.owner, '') AS owner, d.name AS name, collect(d) AS same
UNWIND range(0, size(same) - 1) AS i
WITH same[i] AS d, CASE WHEN $project STARTS WITH 'https://' THEN substring($project, 8) ELSE $project END + '!' + path + '#' + kind + ':'
         + CASE WHEN owner = '' THEN name ELSE owner + '.' + name END + CASE WHEN i = 0 THEN '' ELSE '~' + toString(i + 1) END AS key
WITH collect({d: d, key: key}) AS all, split($ids, '|') AS wanted
UNWIND [x IN all WHERE x.key IN wanted] AS picked
WITH all, wanted, picked.d AS d, picked.key AS id
WITH d, id, [k IN range(0, size(wanted) - 1) WHERE wanted[k] = id][0] AS at,
     CASE WHEN d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'object', 'type']
          THEN reduce(acc = '', m IN [x IN all WHERE x.d.owner = d.name AND x.d.path = d.path] | CASE WHEN size(acc) > 6000 THEN acc ELSE acc + coalesce(m.d.text, toString(m.d.fromLine) + ': ' + coalesce(m.d.signature, m.d.name)) + '\n' END)
          ELSE coalesce(d.text, '') END AS body
RETURN id, d.language AS language, d.kind AS kind, CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS name,
       d.name AS simpleName, d.owner AS owner, d.signature AS signature, d.javadoc AS doc, d.annotationText AS annotations,
       d.path AS file, d.fromLine AS line, d.toLine AS toLine, d.url AS url,
       CASE WHEN size(body) > 6000 THEN substring(body, 0, 6000) + '\n…' ELSE body END AS code
ORDER BY at
AskContext — Declarations of an indexed project by id ('|' between ids), each with what an explanation needs: its signature, annotations and doc; its code (a function's lines, numbered; a type's members, up to about 4,000 characters); the functions and methods elsewhere that call it or use the type (`callers`, at most 8 listed of `callerCount`), and the declarations of the same language its code calls or uses (`callees`). Calls are matched by NAME in the code's text, so a common name is over-counted. Test code is left out of callers and callees unless the declaration is itself a test. Pass `names` and `calls` and it reads only the files the ids are in, the code that mentions their names and the declarations their code names: a second or later declaration of one name in a file that a caller shares with one that does not mention the name may then carry the first's id.
MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(d:CodeDeclaration)
WHERE any(i IN split($ids, '|') WHERE i CONTAINS ('!' + d.path + '#'))
WITH collect(d) AS inFiles
OPTIONAL MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(c:CodeDeclaration)
WHERE c.kind IN ['function', 'method', 'constructor'] AND c.text IS NOT NULL
  AND any(n IN CASE WHEN $names = '' THEN [''] ELSE split($names, '|') END
          WHERE c.text CONTAINS (' ' + n + ' ') OR c.text CONTAINS (' ' + n + '(') OR c.text CONTAINS (' ' + n + '<') OR c.text CONTAINS (' ' + n + '.')
             OR c.text CONTAINS (' ' + n + ')') OR c.text CONTAINS ('(' + n + ' ') OR c.text CONTAINS ('(' + n + '.') OR c.text CONTAINS ('<' + n + '>')
             OR c.text CONTAINS ('<' + n + ',') OR c.text CONTAINS (' ' + n + '::') OR c.text CONTAINS (': ' + n + ',') OR c.text CONTAINS (' ' + n + '\n')
             OR c.text CONTAINS ('.' + n + '(') OR c.text CONTAINS ('(' + n + '(') OR c.text CONTAINS ('!' + n + '(') OR c.text CONTAINS ('\t' + n + '(')
             OR c.text CONTAINS ('::' + n) OR c.text CONTAINS ('.' + n + ' {') OR c.text CONTAINS ('.' + n + '{'))
WITH inFiles, collect(c) AS naming
OPTIONAL MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(e:CodeDeclaration)
WHERE $calls = '' OR (e.name IN split($calls, '|')
  AND e.kind IN ['function', 'method', 'constructor', 'class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'object', 'type'])
WITH inFiles, naming, collect(e) AS called
UNWIND inFiles + naming + called AS d
WITH DISTINCT d
WITH d ORDER BY d.fromLine, d.id
WITH d.path AS path, d.kind AS kind, coalesce(d.owner, '') AS owner, d.name AS name, collect(d) AS same
UNWIND range(0, size(same) - 1) AS i
WITH same[i] AS d, CASE WHEN $project STARTS WITH 'https://' THEN substring($project, 8) ELSE $project END + '!' + path + '#' + kind + ':'
         + CASE WHEN owner = '' THEN name ELSE owner + '.' + name END + CASE WHEN i = 0 THEN '' ELSE '~' + toString(i + 1) END AS key
WITH collect({d: d, key: key, code: d.kind IN ['function', 'method', 'constructor'], test: toLower(d.path) CONTAINS 'test',
              type: d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'object', 'type']}) AS all
UNWIND [x IN all WHERE x.key IN split($ids, '|')] AS picked
WITH all, picked.d AS d, picked.key AS id, picked.type AS isType, picked.test AS isTest
WITH all, d, id, isType, isTest,
     CASE WHEN isType
          THEN [' ' + d.name + ' ', ' ' + d.name + '(', ' ' + d.name + '<', ' ' + d.name + '.', ' ' + d.name + ')', '(' + d.name + ' ', '(' + d.name + '.', '<' + d.name + '>', '<' + d.name + ',', ' ' + d.name + '::', ': ' + d.name + ',', ' ' + d.name + '\n']
          ELSE ['.' + d.name + '(', ' ' + d.name + '(', '(' + d.name + '(', '!' + d.name + '(', '\t' + d.name + '(', '::' + d.name, '.' + d.name + ' {', '.' + d.name + '{'] END AS uses
WITH all, d, id, isType, isTest,
     [x IN all WHERE x.code AND x.d.text CONTAINS d.name AND x.key <> id AND (isTest OR NOT x.test)
        AND NOT (x.d.path = d.path AND x.d.fromLine <= d.fromLine AND x.d.toLine >= d.toLine)
        AND NOT (x.d.path = d.path AND x.d.fromLine >= d.fromLine AND x.d.toLine <= d.toLine)
        AND any(u IN uses WHERE x.d.text CONTAINS u)] AS callers,
     [x IN all WHERE isType AND x.d.owner = d.name AND x.d.path = d.path] AS members
WITH all, d, id, isType, isTest, callers, members,
     CASE WHEN isType THEN reduce(acc = '', m IN members | CASE WHEN size(acc) > 4000 THEN acc ELSE acc + coalesce(m.d.text, toString(m.d.fromLine) + ': ' + coalesce(m.d.signature, m.d.name)) + '\n' END)
          ELSE coalesce(d.text, '') END AS body
WITH d, id, callers, members, body,
     [x IN all WHERE size(x.d.name) > 3 AND body CONTAINS x.d.name AND x.key <> id AND x.d.language = d.language AND (x.code OR x.type) AND (isTest OR NOT x.test)
        AND NOT (x.d.path = d.path AND x.d.fromLine >= d.fromLine AND x.d.toLine <= d.toLine)
        AND NOT (x.d.path = d.path AND x.d.fromLine <= d.fromLine AND x.d.toLine >= d.toLine)
        AND any(u IN CASE WHEN x.code THEN ['.' + x.d.name + '(', ' ' + x.d.name + '(', '(' + x.d.name + '(', '!' + x.d.name + '(', '::' + x.d.name]
                          ELSE [' ' + x.d.name + ' ', ' ' + x.d.name + '(', ' ' + x.d.name + '<', ' ' + x.d.name + '.', '(' + x.d.name + ' ', '(' + x.d.name + '.', '<' + x.d.name + '>', ' ' + x.d.name + '::', ': ' + x.d.name] END
               WHERE body CONTAINS u)] AS callees
RETURN id, d.language AS language, d.kind AS kind, CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS name, d.name AS simpleName,
       d.signature AS signature, d.javadoc AS doc, d.annotationText AS annotations, d.path AS file, d.fromLine AS line, d.toLine AS toLine, d.url AS url,
       CASE WHEN size(body) > 4000 THEN substring(body, 0, 4000) + '\n…' ELSE body END AS code, size(members) AS memberCount,
       size(callers) AS callerCount,
       [c IN callers[0..8] | {id: c.key, name: CASE WHEN c.d.owner = '' THEN c.d.name ELSE c.d.owner + '.' + c.d.name END, kind: c.d.kind, file: c.d.path, line: c.d.fromLine, url: c.d.url}] AS callers,
       size(callees) AS calleeCount,
       [c IN callees[0..12] | {id: c.key, name: CASE WHEN c.d.owner = '' THEN c.d.name ELSE c.d.owner + '.' + c.d.name END, kind: c.d.kind, file: c.d.path, line: c.d.fromLine, url: c.d.url}] AS callees,
       'name' AS resolution
AnswerFromCode — An answer to a question about an indexed project, written from its code: the declarations given (ids, '|' between them, best first) are numbered [1], [2], … in that order, each handed to the model with its signature, annotations, doc, code (more for the first three) and the names of what calls it and what it calls (matched by name), and `synthesize` traces through them to explain how the code does what is asked, citing each declaration it relies on by its number ([2], or [2:30-41] for lines). One model call. It answers only from the code given: what the declarations do not show, it says is not shown. Find the ids with MatchDeclarations and SearchCode, and their code with Declarations; pass `names` and `calls` to read only what the answer needs (as AskContext does).
MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(d:CodeDeclaration)
WHERE any(i IN split($ids, '|') WHERE i CONTAINS ('!' + d.path + '#'))
WITH collect(d) AS inFiles
OPTIONAL MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(c:CodeDeclaration)
WHERE c.kind IN ['function', 'method', 'constructor'] AND c.text IS NOT NULL
  AND any(n IN CASE WHEN $names = '' THEN [''] ELSE split($names, '|') END
          WHERE c.text CONTAINS (' ' + n + ' ') OR c.text CONTAINS (' ' + n + '(') OR c.text CONTAINS (' ' + n + '<') OR c.text CONTAINS (' ' + n + '.')
             OR c.text CONTAINS (' ' + n + ')') OR c.text CONTAINS ('(' + n + ' ') OR c.text CONTAINS ('(' + n + '.') OR c.text CONTAINS ('<' + n + '>')
             OR c.text CONTAINS ('<' + n + ',') OR c.text CONTAINS (' ' + n + '::') OR c.text CONTAINS (': ' + n + ',') OR c.text CONTAINS (' ' + n + '\n')
             OR c.text CONTAINS ('.' + n + '(') OR c.text CONTAINS ('(' + n + '(') OR c.text CONTAINS ('!' + n + '(') OR c.text CONTAINS ('\t' + n + '(')
             OR c.text CONTAINS ('::' + n) OR c.text CONTAINS ('.' + n + ' {') OR c.text CONTAINS ('.' + n + '{'))
WITH inFiles, collect(c) AS naming
OPTIONAL MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(e:CodeDeclaration)
WHERE $calls = '' OR (e.name IN split($calls, '|')
  AND e.kind IN ['function', 'method', 'constructor', 'class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'object', 'type'])
WITH inFiles, naming, collect(e) AS called
UNWIND inFiles + naming + called AS d
WITH DISTINCT d
WITH d ORDER BY d.fromLine, d.id
WITH d.path AS path, d.kind AS kind, coalesce(d.owner, '') AS owner, d.name AS name, collect(d) AS same
UNWIND range(0, size(same) - 1) AS i
WITH same[i] AS d, CASE WHEN $project STARTS WITH 'https://' THEN substring($project, 8) ELSE $project END + '!' + path + '#' + kind + ':'
         + CASE WHEN owner = '' THEN name ELSE owner + '.' + name END + CASE WHEN i = 0 THEN '' ELSE '~' + toString(i + 1) END AS key
WITH collect({d: d, key: key, code: d.kind IN ['function', 'method', 'constructor'], test: toLower(d.path) CONTAINS 'test',
              type: d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'object', 'type']}) AS all, split($ids, '|') AS wanted
UNWIND [x IN all WHERE x.key IN wanted] AS picked
WITH all, wanted, picked.d AS d, picked.key AS id, picked.type AS isType, picked.test AS isTest
WITH all, d, id, isType, isTest, [k IN range(0, size(wanted) - 1) WHERE wanted[k] = id][0] + 1 AS num,
     CASE WHEN isType
          THEN [' ' + d.name + ' ', ' ' + d.name + '(', ' ' + d.name + '<', ' ' + d.name + '.', ' ' + d.name + ')', '(' + d.name + ' ', '(' + d.name + '.', '<' + d.name + '>', '<' + d.name + ',', ' ' + d.name + '::', ': ' + d.name + ',', ' ' + d.name + '\n']
          ELSE ['.' + d.name + '(', ' ' + d.name + '(', '(' + d.name + '(', '!' + d.name + '(', '\t' + d.name + '(', '::' + d.name, '.' + d.name + ' {', '.' + d.name + '{'] END AS uses
WITH all, d, id, isType, isTest, num,
     [x IN all WHERE x.code AND x.d.text CONTAINS d.name AND x.key <> id AND (isTest OR NOT x.test)
        AND NOT (x.d.path = d.path AND x.d.fromLine <= d.fromLine AND x.d.toLine >= d.toLine)
        AND NOT (x.d.path = d.path AND x.d.fromLine >= d.fromLine AND x.d.toLine <= d.toLine)
        AND any(u IN uses WHERE x.d.text CONTAINS u)] AS callers,
     CASE WHEN num <= 3 THEN 6000 ELSE 2500 END AS budget
WITH all, d, id, isType, isTest, num, callers, budget,
     CASE WHEN isType THEN reduce(acc = '', m IN [x IN all WHERE x.d.owner = d.name AND x.d.path = d.path] | CASE WHEN size(acc) > budget THEN acc ELSE acc + coalesce(m.d.text, toString(m.d.fromLine) + ': ' + coalesce(m.d.signature, m.d.name)) + '\n' END)
          ELSE coalesce(d.text, '') END AS body
WITH d, num, callers, budget, body,
     [x IN all WHERE size(x.d.name) > 3 AND body CONTAINS x.d.name AND x.key <> id AND x.d.language = d.language AND (x.code OR x.type) AND (isTest OR NOT x.test)
        AND NOT (x.d.path = d.path AND x.d.fromLine >= d.fromLine AND x.d.toLine <= d.toLine)
        AND NOT (x.d.path = d.path AND x.d.fromLine <= d.fromLine AND x.d.toLine >= d.toLine)
        AND any(u IN CASE WHEN x.code THEN ['.' + x.d.name + '(', ' ' + x.d.name + '(', '(' + x.d.name + '(', '!' + x.d.name + '(', '::' + x.d.name]
                          ELSE [' ' + x.d.name + ' ', ' ' + x.d.name + '(', ' ' + x.d.name + '<', ' ' + x.d.name + '.', '(' + x.d.name + ' ', '(' + x.d.name + '.', '<' + x.d.name + '>', ' ' + x.d.name + '::', ': ' + x.d.name] END
               WHERE body CONTAINS u)] AS callees
WITH num, '[' + toString(num) + '] ' + d.language + ' ' + d.kind + ' ' + CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END
       + ', in ' + d.path + ' lines ' + toString(d.fromLine) + '-' + toString(d.toLine) + '\n'
       + reduce(a = '', t IN coalesce(d.annotationText, []) | a + t + '\n') + coalesce(d.signature, '') + '\n'
       + CASE WHEN coalesce(d.javadoc, '') = '' THEN '' ELSE d.javadoc + '\n' END
       + CASE WHEN size(body) > budget THEN substring(body, 0, budget) + '\n…' ELSE body END
       + '\nCalled or used by (matched by name): ' + CASE WHEN size(callers) = 0 THEN 'nothing in this project' ELSE reduce(a = '', c IN callers[0..6] | a + CASE WHEN c.d.owner = '' THEN c.d.name ELSE c.d.owner + '.' + c.d.name END + '; ') + CASE WHEN size(callers) > 6 THEN 'and ' + toString(size(callers) - 6) + ' more' ELSE '' END END
       + '\nCalls or uses (matched by name): ' + CASE WHEN size(callees) = 0 THEN 'nothing declared in this project' ELSE reduce(a = '', c IN callees[0..10] | a + CASE WHEN c.d.owner = '' THEN c.d.name ELSE c.d.owner + '.' + c.d.name END + '; ') END AS item
ORDER BY num
RETURN synthesize(item, 'Answer this question about the code of ' + $project + ': ' + $question
       + ' Explain HOW it works by tracing through the code given, step by step: what each declaration does, what it calls and in what order, and where data comes from and goes. Cite every declaration you rely on by its item number in square brackets, like [2], or with its lines after a colon, like [2:30-41]; never put a bare line number in square brackets. Name classes and methods in backticks. Use only the code given; where it does not show something the question needs, say so plainly rather than guess. Be direct: lead with the answer, then the trace, in at most about 250 words.') AS answer,
       count(item) AS declarations

What an empty panel means

The views read every file of the languages they cover, so an empty answer means none matched — no endpoint in a framework the route styles know, no name shared across languages. A repository that could not be read says so instead.
