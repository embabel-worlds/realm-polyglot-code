Where languages meet

How it works

Reading the code

Nothing about your project is uploaded or kept. When you map it, the appliance reads it where it lives: a repository at the commit its branch or tag points to now (fetched once without history, then kept by commit — a commit never changes), or a folder in the workspace the appliance owner mounted, read afresh each time. TypeScript, JavaScript, Python, Go, Rust, C, C++, C#, Ruby, PHP, Kotlin, Scala and Swift are parsed with tree-sitter, tolerant of code that does not compile; Java's names are resolved through the file's own imports and types. Each file is bounded in size and parse time, and one that is skipped is reported.

One model for every language

Every language's files, declarations, imports and calls are children of the same parents — Source, SourceDeclaration, SourceImport, CallSite — so each view below is one query over all of them. Endpoints come from route styles kept as data (how each framework declares a route), not code: a framework the atlas does not know is a row to add.

Honest about calls

Syntax names a call's target but cannot say which function it is. Outside Java a call is matched by name, and every call row says so (resolution: name). "Who calls save" lists every call to something called save.

Every view, with the Cypher that runs

ProjectLanguages — What a project is written in: files, lines and syntax errors per language. The first question to ask of an unfamiliar repository.
MATCH (p:CodeProject {key: $project})-[:HAS_SOURCE]->(s:Source)
RETURN s.language AS language, count(s) AS files, sum(s.lines) AS lines, sum(coalesce(s.errors, 0)) AS syntaxErrors
Routes — Every HTTP endpoint a project declares, whatever its language and framework: Spring and Kotlin mappings, ASP.NET attributes, NestJS and FastAPI decorators, Rocket attributes, Express, Gin and Laravel router calls, Django URL patterns, Rails resources — with the method, the path, the handler and the line (`test` marks one declared in a test file). Also the paths routes sit under (role prefix), whole REST resources (role resource) and calls the code makes to other services (role client). Matched by the route styles in reference data (RouteStyle); a framework missing there is a row to add, not code to write. Paths are as each route writes them: a route's full path is the prefix row in the same file (a class's @RequestMapping, [Route] or @Controller) joined to its own. A Rails or DRF resource is one row for the REST resource it declares.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration)
WHERE size(d.annotationText) > 0
MATCH (s:RouteStyle {shape: 'annotation'})
WHERE d.language IN s.languages
WITH d, s, [t IN d.annotationText WHERE toLower(t) CONTAINS s.pattern] AS hits
WHERE size(hits) > 0
WITH d, s, hits[0] AS a
RETURN s.role AS role, s.method AS method,
       CASE WHEN a CONTAINS '"' THEN split(a, '"')[1] WHEN a CONTAINS "'" THEN split(a, "'")[1] ELSE '' END AS path,
       s.framework AS framework, d.language AS language,
       CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS handler,
       a AS declaredAs, toLower(d.path) CONTAINS 'test' AS test, d.path AS file, d.fromLine AS line, d.url AS url
UNION ALL
MATCH (p:CodeProject {key: $project})-[:CALLS]->(c:CallSite)
WHERE size(c.arguments) > 0
MATCH (s:RouteStyle {shape: 'call'})
WHERE c.method = s.pattern AND c.language IN s.languages AND (size(s.receivers) = 0 OR c.receiver IN s.receivers)
WITH c, s, c.arguments[0] AS first
WHERE first STARTS WITH '"' OR first STARTS WITH "'" OR first STARTS WITH '`' OR first STARTS WITH "r'" OR first STARTS WITH 'r"' OR first STARTS WITH ':'
WITH c, s, first, [a IN tail(c.arguments) WHERE NOT a =~ '[A-Za-z_][A-Za-z0-9_]*\\s*(:|=)[^:=>].*'] AS named
WITH c, s, first, CASE WHEN size(named) = 0 THEN c.enclosing ELSE named[size(named) - 1] END AS h
RETURN s.role AS role, s.method AS method,
       replace(replace(replace(CASE WHEN first STARTS WITH 'r' OR first STARTS WITH ':' THEN substring(first, 1) ELSE first END, '"', ''), "'", ''), '`', '') AS path,
       s.framework AS framework, c.language AS language,
       CASE WHEN size(h) > 60 THEN '(inline) ' + substring(h, 0, 48) + '…' ELSE h END AS handler,
       c.receiver + '.' + c.method + '(…)' AS declaredAs, toLower(c.path) CONTAINS 'test' AS test, c.path AS file, c.line AS line, c.url AS url
UNION ALL
MATCH (p:CodeProject {key: $project})-[:DECLARES_TYPE]->(t:JavaCodeType)
WHERE size(t.annotationText) > 0
MATCH (s:RouteStyle {shape: 'annotation', role: 'prefix'})
WHERE 'java' IN s.languages
WITH t, s, [x IN t.annotationText WHERE toLower(x) CONTAINS s.pattern] AS hits
WHERE size(hits) > 0
WITH t, s, hits[0] AS a
RETURN s.role AS role, s.method AS method,
       CASE WHEN a CONTAINS '"' THEN split(a, '"')[1] ELSE '' END AS path,
       s.framework AS framework, 'java' AS language, t.name AS handler,
       a AS declaredAs, toLower(t.path) CONTAINS 'test' AS test, t.path AS file, t.line AS line, t.url AS url
ORDER BY role, test, path, method
SharedNames — Names declared in more than one language of the same project — the vocabulary a backend and its frontend share (an Item model in Python and an Item interface in TypeScript), or code ported from one language to another. Types, functions and methods only.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration)
WHERE d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'type', 'protocol', 'function', 'method', 'object']
  AND size(d.name) > 3
WITH d.name AS name, collect(DISTINCT d.language) AS languages, collect(DISTINCT d.language + ' ' + d.kind + ' in ' + d.path) AS where
WHERE size(languages) > 1
RETURN name, languages, size(languages) AS languageCount, where
ORDER BY languageCount DESC, name LIMIT 200
ExternalDependencies — What a project imports from outside itself, per language: every module, package or header its files import that is not a relative path, with how many files import it. The dependencies that matter are the ones the code actually uses.
MATCH (p:CodeProject {key: $project})-[:IMPORTS]->(i:SourceImport)
WHERE i.imported <> '' AND NOT i.imported STARTS WITH '.' AND NOT i.imported STARTS WITH '/'
RETURN i.language AS language, i.imported AS imported, count(DISTINCT i.path) AS files
ORDER BY files DESC, imported LIMIT 300
DocCoverage — How much of a project is documented, per language and kind: declarations of types, functions and methods, and how many carry a doc comment or docstring.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration)
WHERE d.kind IN ['class', 'interface', 'struct', 'enum', 'trait', 'record', 'protocol', 'function', 'method', 'constructor']
WITH d.language AS language, d.kind AS kind, count(d) AS declared, sum(CASE WHEN coalesce(d.javadoc, '') <> '' THEN 1 ELSE 0 END) AS documented
RETURN language, kind, declared, documented, round(100.0 * documented / declared) AS percent
ORDER BY language, declared DESC
LargestFunctions — The longest functions and methods in a project, in every language — where complexity lives, and the first candidates to split.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration)
WHERE d.kind IN ['function', 'method', 'constructor']
RETURN d.language AS language, CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS name,
       d.toLine - d.fromLine + 1 AS lines, d.signature AS signature, d.path AS file, d.fromLine AS line, d.url AS url
ORDER BY lines DESC LIMIT 25
WhereDefined — Where a name is declared, in every language: a class, function, method, field or constant called exactly this, with its kind, owner, signature, doc and line. Java's types are matched by their simple name.
MATCH (p:CodeProject {key: $project})-[:DECLARES]->(d:SourceDeclaration {name: $name})
RETURN d.language AS language, d.kind AS kind, d.owner AS owner, d.name AS name, d.signature AS signature,
       d.javadoc AS doc, d.path AS file, d.fromLine AS line, d.url AS url
UNION ALL
MATCH (p:CodeProject {key: $project})-[:DECLARES_TYPE]->(t:JavaCodeType {simpleName: $name})
RETURN 'java' AS language, t.kind AS kind, '' AS owner, t.name AS name, t.kind + ' ' + t.simpleName AS signature,
       '' AS doc, t.path AS file, t.line AS line, t.url AS url
WhoCalls — Every call to a name, in every language a project is written in tree-sitter reads, with what it is called on, its arguments and the function it is in. Calls are matched by NAME (resolution 'name'): this is every call to something called that, not proof of which one — the receiver says more. Java calls are not listed here; its jar and source realms resolve them exactly.
MATCH (p:CodeProject {key: $project})-[:CALLS]->(c:CallSite {method: $name})
RETURN c.language AS language, c.receiver AS receiver, c.method AS method, c.arguments AS arguments,
       c.enclosing AS caller, c.resolution AS resolution, c.path AS file, c.line AS line, c.url AS url
ORDER BY file, line LIMIT 1000
SearchCode — Code found by what it does: the declarations of an indexed project whose purpose is closest to a description, in every language tree-sitter reads, best first, with the declaration's live row. Ask in words ("retry with backoff", "where money is formatted"), not names; WhereDefined finds names. A project is searchable once it is an IndexedProject and the code-declarations source has run. `id` is the declaration's key, the same one its document is named by (code://<id>), which a new commit or a move leaves as it is.
MATCH (c:Concept {value: $query})-[r:RELEVANT_TO]->(doc:CodeSearchHit)
WHERE 'code' IN doc.tags AND doc.uri STARTS WITH 'code://' + CASE WHEN $project STARTS WITH 'https://' THEN substring($project, 8) ELSE $project END + '!'
WITH doc, r ORDER BY r.score DESC LIMIT 20
WITH collect({key: substring(doc.uri, 7), score: r.score}) AS hits
MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(d:CodeDeclaration)
WITH hits, ip, d ORDER BY d.fromLine, d.id
WITH hits, ip.key AS project, d.path AS path, d.kind AS kind, coalesce(d.owner, '') AS owner, d.name AS name, collect(d) AS same
UNWIND range(0, size(same) - 1) AS i
WITH hits, same[i] AS d, CASE WHEN project STARTS WITH 'https://' THEN substring(project, 8) ELSE project END + '!' + path + '#' + kind + ':'
         + CASE WHEN owner = '' THEN name ELSE owner + '.' + name END + CASE WHEN i = 0 THEN '' ELSE '~' + toString(i + 1) END AS key
UNWIND hits AS h
WITH h, d, key WHERE h.key = key
RETURN d.language AS language, d.kind AS kind, CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS name,
       d.signature AS signature, d.javadoc AS doc, d.path AS file, d.fromLine AS line, d.url AS url, h.score AS score, key AS id
ORDER BY score DESC
Declaration — One declaration of an indexed project by its key, as a code search hit or a cited answer names it (code://<key>): its language, kind, name, signature, doc and line as the project reads now. No row when the project no longer declares it: it was deleted or renamed since it was indexed.
MATCH (ip:IndexedProject {key: $project})-[:DECLARES]->(d:CodeDeclaration)
WITH ip, d ORDER BY d.fromLine, d.id
WITH ip.key AS project, d.path AS path, d.kind AS kind, coalesce(d.owner, '') AS owner, d.name AS name, collect(d) AS same
UNWIND range(0, size(same) - 1) AS i
WITH same[i] AS d, CASE WHEN project STARTS WITH 'https://' THEN substring(project, 8) ELSE project END + '!' + path + '#' + kind + ':'
         + CASE WHEN owner = '' THEN name ELSE owner + '.' + name END + CASE WHEN i = 0 THEN '' ELSE '~' + toString(i + 1) END AS key
WITH d, key WHERE key = $id
RETURN key AS id, d.language AS language, d.kind AS kind, CASE WHEN d.owner = '' THEN d.name ELSE d.owner + '.' + d.name END AS name,
       d.name AS simpleName, d.owner AS owner, d.signature AS signature, d.javadoc AS doc, d.path AS file, d.fromLine AS line, d.toLine AS toLine, d.url AS url
IndexedProjects — The projects kept searchable by meaning: each one's declarations are read by the code-declarations documents source every 15 minutes, and only declarations whose text changed are embedded again.
MATCH (ip:IndexedProject)
RETURN ip.key AS project, ip.label AS label
ORDER BY project

What an empty panel means

The views read every file of the languages they cover, so an empty answer means none matched — no endpoint in a framework the route styles know, no name shared across languages. A repository that could not be read says so instead.
